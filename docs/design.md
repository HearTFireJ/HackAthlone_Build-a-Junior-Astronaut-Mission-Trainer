# 游戏设计（只写已经定下来的）

这里的每一条都经作者确认。还在讨论的事写在 `progress.md`，确认后再移到这里。

## 一句话

孩子当月球基地的小指挥官，每天给宇航员派活，在太阳风暴的威胁下撑到补给船抵达，同时尽量多做科研。

## 已定（2026-11-13）

- **设定**：月球南极基地。玩家是地面指挥中心的小指挥官。
- **节奏**：一回合是一天，共 10 天。撑到第 10 天补给船抵达算过关。一局 4–5 分钟。
- **主要操作**：每天给每个宇航员派一个活。不做电量分配条。
- **避难舱**：可以让全员进避难舱。当天不受辐射，但没人干活，物资照常消耗。
- **科研目标**：过关之外按科研完成度给 1–3 星。躲一天或休息一天，丢掉的是当天的科研和生产。
- **随机事件**：只有太阳风暴，由 NASA DONKI 的真实记录驱动。
- **通讯**：不做通讯延迟（月球到地球只有一秒多，按天推进的游戏里表现不出来）。风暴期间通讯中断，当天收不到预报。
- **基调**：没有人死亡。宇航员只会累或生病。失败是紧急撤离回地球，附一份任务报告，鼓励再来一局。
- **画面**：2D 单屏，一张基地图加每天一段指挥中心来信。不做 3D。

## 已定（2026-11-13 深夜，第二轮）

- **资源**：电、氧气、食物，共三条。
- **人手**：3 名宇航员，每人每天干一样：
  - 修太阳能板：加电。
  - 维护制氧机：加氧气。
  - 温室种菜：加食物。
  - 出舱做科研：加科研星星，但耗氧气，而且人在舱外。
  - 休息。
  - 人比活少，每天必然要放弃一样。
- **预报**：每天早上指挥中心给一句“今天风暴可能性：低、中、高”。孩子先派活，再揭晓当天实际发生了什么。预报有时会错。
- **数据怎么用**：每一局是一段真实的 10 天。先内置三段：2017 年 9 月、2024 年 5 月、一段平静期，游戏里标明是历史存档数据。核心玩法完成后再加“最近 10 天”的实时模式。
- **和爱尔兰的联系**：指挥中心设在 Athlone；三名宇航员用爱尔兰名字；I-LOFAR 写成灵感来源并注明出处。
- **美术**：基地和宇航员用代码画（SVG、CSS、emoji）；背景用 NASA 公开的月球南极真实照片并标来源；先不用 AI 生成图片。
- **设备**：电脑横屏优先，因为展示时是笔记本投屏。手机上布局改成上下排列，能完整玩完一局，不追求好看。
- **语言**：界面只做英文。

## 规则第一版（数值由 agent 先定，作者试玩后调）

作者把具体数值交给 agent 先定一版。下面是 2026-11-13 夜里定的，全部集中在 `src/game/mission.ts` 的 `RULES` 里，改数值只改那一处。

- **物资**：电、氧气、食物各从 8 开始，上限 10。基地每天各消耗 2。
- **干活**：修太阳能板、维护制氧机、种菜，每人每天各加 3。
- **科研**：每人每天加 1 颗科研星，额外耗 1 氧气。宇航服早上从氧气罐里充气，罐里不够 1 就出不了舱，那个人改为休息。
- **电是枢纽**：早上电为 0 时，制氧机和温室当天不出产。
- **健康**：每人 4 颗心。休息一天加 1。待在避难舱也算休息。
- **健康怎么算**：当天的风暴伤害、短缺伤害、休息回血先加在一起，再限制在 0 到 4 之间。所以只剩 1 颗心的人在舱内休息时遇到严重风暴，照样会病倒。
- **短缺**：当天氧气或食物不够用，每缺一样全员减 1，而且当天休息不回血。
- **风暴**：在舱外（做科研）减 2，严重风暴减 3；在舱内减 1，严重风暴减 2；在避难舱不受影响。
- **病倒**：健康为 0 的宇航员当天只能休息。
- **结局**：三个人同时病倒就紧急撤离；撑过第 10 天过关。
- **星级**：过关 1 星，科研满 4 颗 2 星，满 8 颗 3 星。
- **一天之内的顺序**：干活，风暴，扣每日消耗，休息回血，判断结局。

这组数值是用程序把所有打法穷举和抽样之后选的，目标是：

- 偷懒的打法在三个任务里都失败：每天躲避难舱、每天全员休息、全员只做科研。
- 平静的任务里，老老实实维持基地就能过关。
- 两个风暴任务里，从不躲避难舱会失败，见到预报高就躲也会失败（物资耗尽），有选择地躲才能过关。

这些都写成了测试，数值改坏了测试会报错。

2026-11-14 凌晨让 Codex 只读审查了一遍规则，按它的意见改了三处：健康先加总再封顶（原来先封底再回血，弱的人休息时等于免疫风暴）；氧气罐空了不能出舱做科研（原来没氧气也能拿科研星）；避难舱里也能休息回血（原来病人进避难舱反而好不了）。

## 技术

- Vite + React + TypeScript。
- 游戏规则放在 `src/game/`，是纯 TypeScript，不引用 React，配 Vitest 测试。
- 界面放在 `src/components/`，只负责显示和接收点击。
- 内置的真实数据放在 `src/data/`。
- 推送到 `main` 后由 GitHub Actions 自动构建并发布到 GitHub Pages。

## 和题目的对应

题目原文列了五个决策领域：生命维持、辐射防护、电力分配、食物生产、通讯延迟。我们覆盖前四个；通讯用“风暴期间通讯中断”表现，并在给评委的数据说明里如实写明。
